# AI生成コンテンツを公開する前のチェックリスト

ChatGPTなどで作った文章・画像・資料を、そのまま公開する前に最低限確認したい項目をまとめた無料版チェックリストです。

## 7項目だけ先に確認

- **事実** — 数値・固有名詞・日付・制度・引用元を一次情報で確認したか
- **根拠** — 「〜と言われています」だけで済ませず、読者が追える根拠があるか
- **権利** — 引用、画像、商標、第三者の文章などを不用意に再利用していないか
- **個人情報** — 名前、メール、住所、アカウント情報などが紛れ込んでいないか
- **誤解** — AIの推測を確認済み事実のように書いていないか
- **公開条件** — 公開前に人間が確認すべき箇所と、公開を止める条件が明確か
- **最終確認** — タイトル・本文・リンク・添付ファイルを公開物としてもう一度見直したか

## こんな用途向け

ブログ、note、SNS投稿、社内文書、AI生成レポート、商品説明、調査メモなど、AIが下書きに関わる公開物全般を想定しています。
