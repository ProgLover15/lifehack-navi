# AIに仕事を任せる前に決めること：未確認を「完了」にしないためのチェック

AIは、入力が曖昧でもそれらしい答えを返せます。問題は、**確認できていないことまで「できた」に見えること**です。

この無料版では、AIへ仕事を渡す前後に最低限固定したい項目を整理します。

## 最初に固定する7項目

- **正本** — 何を根拠データとして使うか
- **取得時点** — その情報はいつ観測したものか
- **権限境界** — AIが触ってよい範囲／触ってはいけない範囲
- **成功条件** — 何が確認できたら完了とするか
- **停止条件** — どこで止めるか
- **未確認事項** — 分からないことを分からないまま残せているか
- **検収** — AIの出力を実環境・一次情報で照合したか
