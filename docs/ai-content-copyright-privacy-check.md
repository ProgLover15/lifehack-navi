# AI生成コンテンツの著作権・個人情報 公開前チェック

AIで作った文章・画像・資料を公開するとき、内容の正しさだけでなく、第三者の権利や個人情報も確認する必要があります。

## 公開前の6項目

- **第三者の文章** — 長い引用や特徴的な表現をそのまま使っていないか
- **画像・素材** — 出所不明の画像、ロゴ、写真、スクリーンショットを含めていないか
- **商標・ブランド** — 公式サービスと誤認される見せ方になっていないか
- **個人情報** — 氏名、住所、メール、電話番号、アカウント情報が残っていないか
- **内部情報** — 非公開資料、顧客情報、社内情報をAI入力から転載していないか
- **公開範囲** — 本当に公開してよい情報だけに絞れているか

## 特に止めて確認するケース

個人を特定できる情報、契約書・顧客資料、出典不明の画像、第三者の長文、秘密情報らしき内容が含まれる場合は、そのまま公開しない方が安全です。
