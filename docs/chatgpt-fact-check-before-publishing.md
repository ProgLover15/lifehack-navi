# ChatGPTの文章を公開する前のファクトチェック

AIの文章は読みやすくても、固有名詞・数字・日付・制度・引用が間違っていることがあります。公開前に短時間で確認するための無料チェックです。

## 最低限見る5点

1. **数字** — 金額、割合、件数、年齢、日付を元資料と照合する
2. **固有名詞** — 人名、会社名、制度名、商品名の表記を確認する
3. **一次情報** — 公式サイト、原文、法令、論文など元情報へ戻る
4. **引用** — 実在する文言か、文脈を変えていないか確認する
5. **断定** — AIの推測や一般論を「確認済み事実」と書いていないか確認する

## 公開を止めた方がいい状態

- 出典が追えない重要な数字がある
- 重要な固有名詞を確認できない
- 医療・法律・金融など高リスク分野で一次確認がない
- 引用元を特定できない
- 「たぶん」「一般的に」を断定へ変換している
